Learning Journal

Week 1:

In week 1 hebben we het gehad over DLC, (development-lifecycel). In de DLC zijn verschillende fases: analyseren, ontwerpen, bouwen, integreren en testen. we hebben in de ontwerpfase opgeschreven/geschetst wat we over ons zelf willen vertellen in ons visitekaartje. In de bouwfase hebben we onze schets gerealiseerd in code (html,css,js). We hebben github en VScodium geinstaleerd op de laptop. We hebben ook meegekregen hoe je moet forken en downloaden. We hebben in HTML gewerkt en geleerd wat je waar invoert. We hebben geleerd dat je CSS gebruikt voor de vormgeving van in dit geval je visitekaartje. In de integratie fase hebben we alle aanpassingen doorgevoerd zodat iedereen dit kan zien. We zijn meer te weten gekomen over repo. Ook hebben we de website van hva geinspecteerd. Dit hebben we ook gedaan met onze eigen visitekaartje. Je ziet dan de code van de desbetreffende website. Na het leren van de basis stappen zijn we verder gegaan met de breakdown schets. Hierin beschrijf je de HTML en css en hoe je wil dat je visitekaartje er nou eigenlijk uit komt te zien. Daarna hebben we deze toegevoegd in issues en Krijn getagd om feedback te ontvangen. Verder hebben we ervoor gezorgd dat we een live link in Github hebben staan zodat bij aanpassingen deze altijd up to date is. Als je dingen gaat bewerken in je HTML en CSS zorg je ervoor dat je in github desktop commit en pusht, zodat de meest recente versie in je repo staat.

Week 2:

Week 2 stond centraal in het teken van de squad page. We begonnen met het forken van van de leertaak (your tribe squad page). (dit moest 1 teamlid doen). Ook heeft diegene de rest van de teamleden toegevoegd in de repo. Daarna hebben we het team canvas in figma ingevuld. Hierin stonden vragen die we als team samen hebben beantwoord. De opdracht voor de squad page is eigenlijk dat we een website maken met overzicht van alle visitekaartjes van de squad (klas) en interessante plekken op de amstelcampus. We hebben alle visitekaartjes die een live url link hadden verzameld en in figma gezet en besproken. Daarna heb ik 12 inspiratie screenshots verzameld van overzichtpagina's en in figma toegevoegd. Waarna we aan de hand van deze voorbeelden een paar ideeen hebben geschetst. Een ander teamgenoot heeft interessante plekken op de amstelcapus gezocht en ook toegevoegd in figma. Ook hebben we individueel 4 schetsen gemaakt voor de squad pagina en toegevoegd in issues. Aan de hand van deze schetsen hebben we op het whiteboard onze definiteve schets gemaakt met hierbij de HTML elementen. Deze hebben we ook weer toegevoegd in issues en Krijn getagd voor feedback. Hierna hebben we afgesproken dat ieder voor zich thuis de definitieve schets van onze squad page uitwerkt in HTML en CSS. En wanneer we weer samen komen op school onze codes. Tijdens de les hebben we het ook gehad over pixelwaarde en resoluties. Ook hebben we het gehad over media queries, Dit gebruik je om te kiezen hoe en op hoeveel pixels je wil dat je pagina layout veranderd op bijvoorbeeld een smal scherm (telefoon).
